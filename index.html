三平台寫法差異
  • Facebook：第一行就是鉤子，段落分明，資訊可以完整；hashtag 2–3 個就好。
  • Instagram：圖片負責吸睛，前 125 字決定會不會被點「更多」；hashtag 上限 5 個。
  • Threads：像跟朋友聊天，短、有觀點、丟一個問題；上限 500 字，話題標籤 1 個。

AI 連線設定

這個 App 用 Anthropic 的 Claude 寫文案。請貼上你自己的 API 金鑰（到 console.anthropic.com 的 API Keys 建立），用量由你的 Anthropic 帳戶計費。

金鑰只存在這台裝置的瀏覽器，只會傳給 api.anthropic.com。共用電腦請用完按「清除金鑰」。

沒有金鑰也能用：按生成會改用內建範本，並可「複製 AI 提示詞」貼到你慣用的 AI 工具。
